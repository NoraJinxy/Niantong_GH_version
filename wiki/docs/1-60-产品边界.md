## 一句话

念析只做**科研级 EEG 数据 + 流程 + 协作**；不做硬件、不做 SSO、不做 MRI/fMRI、不做通用统计 / ML 平台、不靠转售公共数据为生。

## 1. 数据边界

| 做 | 不做 |
|---|---|
| 接收 BrainVision · EDF · BDF 原始数据 | 不接收用户上传的 `.fif`（FIF 由平台生成） |
| 接收 EEGLAB `.set / .fdt` —— 用户先转 EDF/BDF/BrainVision | 不在导入入口直接接收 `.set / .fdt` |
| 未来支持 CNT · MFF · GDF · MAT · HDF5（高级导入流程） | 当前同步导入入口拒收上述格式 |
| 未来生成正式 BIDS 包到 `bids_exports/` | **`source_uploads/` 与 `fifdata/` 都不是**官方 BIDS raw dataset |
| 溯源分析依赖 MRI / BEM / forward model（作为未来依赖） | 不接收 MRI / DICOM / NIfTI 作为主导入数据 |
| 事件、行为、表型 sidecar（CSV / TSV / JSON）—— 高级导入流程 | 当前不在主入口接收，未来模板化 |

## 2. 功能边界

| 做 | 不做 |
|---|---|
| EEG 研究项治理 + 工作流 + 派生产物 | 实时 EEG 采集（不接管硬件） |
| EEG 常用统计方法（t / ANOVA / 非参数 / 多重比较 / Cluster Permutation / 混合效应） | 通用统计软件全功能替代（SPSS / R 的方差分析全集等） |
| EEG 论文级出图（ERP / PSD / TFR / 脑图 / 网络） | 通用绘图工具（Origin / GraphPad / Tableau） |
| EEG 特征 + 经典 ML + 深度 ML + AutoML | 通用机器学习平台 |
| 节点扩展 + 插件市场（Phase 4） | 任意 DAG / 任意 Python 脚本执行平台 |
| Web 协作 + 研究项级 RBAC | SSO / ORCID / 机构身份联合登录 |
| AI 辅助：流程建议、参数解释、质控摘要、结果解读 | "AI 全自动写论文"或"AI 替代研究者决策" |

## 3. 身份与协作边界

- **不接 SSO / ORCID / 机构 IdP**：v1 只用账号密码。
- **不开放外部注册**：研究项和用户由管理员创建（Phase 4 商业化时再考虑公开注册）。
- **不做即时聊天 / 工单系统**：让团队继续用现有的协作工具（飞书 / Slack / 邮件），念析只承载研究项数据与流程。

## 4. 部署边界

- **数据默认存本地**：研究项数据目录在计算服务器本地磁盘 / 内网存储。
- **云端只存去标识化元数据**：未来公有云方案下，DB / 研究项数据目录仍可放本地。
- **不上云上的患者原始数据**：避免合规风险。
- **不绑定单一云厂商**：服务器要求只需 Ubuntu 22.04 + 基础组件，可迁公司机房。

## 5. 商业化边界

| 做 | 不做 |
|---|---|
| 服务价值来自**平台治理 + 分析流程 + 计算服务 + 质控 + 结果管理** | 不把"转售公共数据本身"作为主要收入 |
| 提供公共数据**索引 / 精选 / 模板**入口，强调来源 + license + 引用 | 不把公共数据当独家资产 |
| PI / PI Plus / PI Pro 资源档位收费 | 不锁基础功能在付费墙后（保持开源 / 免费版可用） |
| 多中心 / 大团队服务定制 | 不做单家客户专属功能（避免分叉） |

## 6. 与"看上去类似但不做"的产品对比

| 像 | 实际不做 |
|---|---|
| EEGLAB / FieldTrip / MNE-Python | 不替代算法库，**而是在它们之上加治理层** |
| BIDS Validator | 不实现 Validator；导出到 `bids_exports/` 后由用户自行跑 |
| Jupyter Hub | 不提供任意 Python 环境；只暴露 NodeSpec 限定的算法接口 |
| OpenNeuro | 不做开放数据共享平台；做私有研究项工作台 |
| GitHub | 不做代码托管；只在脚本扩展接口（Phase 4）借鉴 PR / Review 思路 |
| 临床心电 / 脑电诊断软件 | 不走 NMPA / FDA 临床合规；定位**科研** |

## 7. 何时回到本页

- 评审会上有人提"咱们要不要也支持 fMRI / 电生理硬件 / 通用 ML"。
- 客户希望接 SSO / 单点登录。
- 商业方案出现"开放数据当资产卖"的措辞。
- 用户提 `.fif` 直接上传需求。
- 出现"AI 全自动出论文"需求。

**全部直接引用本页拒绝**，并在 [9-00 更新日志](9-00-更新日志.md) 留一行决策。
