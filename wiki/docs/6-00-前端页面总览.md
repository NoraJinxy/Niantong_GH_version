## 一句话现状

前端使用 Vue 3、Pinia、Vue Router、Axios 和 LiteGraph.js。登录、Dashboard、研究项、导入、Pipeline/Execution 主线已接后端核心链路；观察、统计、作图、机器学习、管理后台多数为静态预览。正式主站域名为 `elysbrain.site`，首页底部展示备案号 `粤ICP备2026062729号`。

## 3. 登录守卫

`router.beforeEach` 会从 `auth` store 恢复 localStorage：

- 访问需要登录的页面且未认证时跳转 `/login`。
- 已登录访问 `/login` 时跳转 `/dashboard`。
- 其它情况正常放行。

## 5.1 Dataset 导入前端口径

当前口径是 Dataset-first：用户先创建或选择 Dataset，系统创建或选择配套 Study，并通过 `study_dataset_mounts` 挂载；上传组件拿到 `studyId/studyId`、`datasetAssetId`、`mountName` 后再调用兼容上传接口。

当前已接入：

- `ImportPage.vue` 默认创建 Dataset Asset，并调用 `datasetAssetApi.bootstrap()` 自动创建配套 Study 和 mount。
- `ImportPage.vue` 以两阶段展示 Dataset 导入：步骤 1 准备 Dataset 目标，步骤 2 上传 EEG 原始数据；上传组件初始态可见，用户可先选择 BrainVision/EDF/BDF 文件，待 Dataset target 就绪后再提交。
- `/datasets?study_id=...` 或 `?study_id=...` 保留 Study-first 快捷入口，但仍要求用户明确 Dataset Asset 和 mount。
- `BidsUploadPanel.vue` 的标题、说明和上传参数已经改为 Dataset working version 语义，调用 `datasetApi.upload()` 时提交 `dataset_asset_id` 和 `mount_name`。
- 页面不展示服务器绝对路径，导入结果优先展示 original upload、Raw BIDS、canonical FIF 和 dataset_files。

仍需 staging 验收：真实浏览器大文件上传、真实后端登录态、真实 MNE 转换、真实 Celery/任务进度，以及 Dataset-first 页面在生产 API 下的异常提示。

## 5.2 Pipeline 页面接入现状

`PipelinePage.vue` 当前承担 Pipeline 编辑器和 Execution detail 的 MVP 主界面：

- Pipeline 保存会携带 `expected_version`。
- Execution 创建对话框提供 `execution_mode` 和 `save_policy`。
- 运行按钮会根据 Pipeline 状态禁用不允许的 Execution。
- LoadData 表格可显示 Dataset Asset 和 mount 信息；后端预览已支持 active mount 下的外部 Dataset。
- Execution detail 提供 `派生数据 / 节点 / 任务 / 输入 / 摘要 / Manifest / Lineage` 分栏，默认进派生数据。
- 派生数据行支持 inline 改名 / 行内 tag 编辑 / 状态切换；底部清理 cached 按钮调用 `runDerivedDatasetCleanup()`。

## 5.3 Results 跨 Execution 浏览页

`ResultsPage.vue` 是新增的跨 Execution 派生数据浏览主页，详见 [3-45 §8](3-45-DerivedDataset.md)：

- 选择 Study → 进入派生数据列表（默认按 `created_at` 降序）。
- 顶部 chip 多维筛选：`data_type / node_types / bids_subject_ids / sessions / tasks / conditions / tags / retention_statuses / run_ids`。
- 表格列：`display_name / data_type / subject / session / task / condition / retention / tags / run / 创建时间`。
- 行内动作：固定 / 设为正式 / 隐藏 / 下载；批量动作：批量改 retention、批量加标签、批量隐藏、清理 cached。
- 详情抽屉：来源链可视化（`upstream_dataset_ids` → `upstream_recording_ids`）+ inline 改名 / 改描述 / 改标签。
- 调用 `listDerivedDatasets / batchUpdateDerivedDatasets / updateDerivedDataset / runDerivedDatasetCleanup`。

## 7. 工作台导航

页面用 `WorkbenchShell` 组件，由 `data/workbenchPages.ts` 维护顶部导航和可选侧栏导航。Dashboard、Dataset 管理、Study 管理、Pipeline/Execution 主工作页关闭全局侧栏；Pipeline 页只保留自身节点库/工作流选择栏，避免双左栏。

| nav | 内容 | 说明 |
|---|---|---|
| `topNavItems` | 仪表盘、研究项管理、分析、派生数据、观察、统计、作图、机器学习 | 顶部主要入口 |
| `sideNavGroups` | 工作台、处理与分析、观察与出图 | 工作台内侧栏入口 |

静态预览入口应保持“预览”或“规划”语义，避免误导为后端能力已上线。

## 7.1 首页备案展示

正式域名 `elysbrain.site` 已备案，备案号为 `粤ICP备2026062729号`。`Index.vue` 首页底部应长期显示备案号，并链接到 `https://beian.miit.gov.cn/`。如果后续新增独立营销页或文档站落在 `elysbrain.site` 子域名下，也应在对应页面底部保留备案展示。
