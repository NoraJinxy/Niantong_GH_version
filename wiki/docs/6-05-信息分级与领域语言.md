## 1. 用户画像

平台用户**不是软件工程师**，是临床和科研侧的脑电分析使用者：

| 维度 | 现实 |
|---|---|
| 学科 | 神经科学、心理学、精神科医生 |
| 编程 | 基本不写代码，部分接触过 MATLAB |
| 数据库 | 不懂 |
| BIDS / FIF / MNE | 知道 EEG 文件格式，但不关心内部结构 |
| 工作流 | 接收数据 → 整理 → 预处理 → 分析（ERP/PSD/TFR）→ 出图写论文 |

**含义**：UI 一切术语必须是研究员日常用语，所有平台内部对象、ID、文件统计、技术格式默认隐藏。

## 2. 四条核心原则

| 原则 | 含义 | 落地示例 |
|---|---|---|
| **领域语言** | 一切 UI 文本用研究员的话讲，不暴露平台内部对象 | "Dataset Asset" → "数据集"；"挂载" → "引用到研究"；"job_id" → "第 N 步" |
| **进度感** | 不显示孤立数字，显示"做到哪一步了"+ "下一步该做什么" | "8 名被试已导入" 比 "文件总数 48" 有意义 |
| **下一步指引** | 任何状态都告诉用户最近能做什么 | "已导入 → 可以开始预处理"（带按钮） |
| **隐藏复杂度** | 技术信息默认折叠在 `<TechnicalFold>` 区，主动展开才看到 | ID / DOI / 文件数 / 内部状态枚举全部 L3 |

> **现状落差（代码尚未完全落实本原则）**：截至 2026-06，`DatasetsPage.vue` 用户可见文案仍出现 "Recording / Records" 等内部对象名（如"按 Recording 管理数据位""Recording 总数"），`StudyDetailPage.vue` 四张统计卡标题直接用英文 "Data / Pipelines / Artifacts"。这与「领域语言」原则、§9 反例都冲突，属**待修复的代码欠账**，不是本页原则变更——以本页原则为目标态。

## 3. 信息分级模型（L1 / L2 / L3）

所有字段按"谁会看 / 何时看"分三层：

| 层级 | 可见者 | 何时看 | 显示方式 |
|---|---|---|---|
| **L1 必看** | 所有研究员 | 进页面即看到 | 大字号 / 卡片标题 / 颜色突出 |
| **L2 选看** | 大部分研究员 | 想查细节时 | 二级区域、卡片底部、tooltip |
| **L3 隐藏** | 平台管理员 / 调试 | 出问题或好奇时 | `<TechnicalFold>` 折叠区 |

### 3.1 角色差异

- **普通研究员**：默认只看 L1。L2 可点开。L3 折叠按钮存在但很少点。
- **数据管理员 / PI**：L1 + 频繁查 L2，偶尔 L3。
- **平台管理员**：所有层级，特别关心 L3 用于排查问题。

## 4. 字段分级清单

### 4.1 数据集字段

| 字段 | 层级 | 显示形式 |
|---|---|---|
| 数据集名称 | L1 | H2 标题 |
| 数据集描述 | L1 | 正文 |
| 状态（草稿/已发布/已撤回） | L1 | 状态徽章 |
| **被试数** | L1 | 大数字 + 图标 |
| **采集任务种类** | L1 | 标签列表（如 "静息态闭眼 / 静息态睁眼"） |
| **数据总时长** | L1 | "24 分钟" |
| **最近导入时间** | L1 | "2 小时前" |
| 当前版本号 | L1 | "v1.0.0 已发布" |
| 主研究项 | L1 | **研究项名称（链接），不显示 ID** |
| 版本历史 | L1 | 时间线 |
| 上传记录列表 | L2 | "详情 ▾" 折叠 |
| 数据集描述 / 协作说明 | L2 | |
| 存储占用 | L2 | "50 MB" |
| QA 报告 | L2 | "QA 已通过 / 未运行" |
| 数据集编码 (code) | **L3** | TechnicalFold |
| 文件总数 / 原始文件数 / BIDS 视图数 / FIF 数 | **L3** | TechnicalFold |
| Concept DOI / Version DOI 字符串 | **L3** | TechnicalFold（L1 显示按钮 "已注册学术 DOI [复制]"） |
| UUID / Storage URI | **L3** | TechnicalFold |
| BIDS 字段细节 | **L3** | TechnicalFold |

### 4.2 研究项字段

| 字段 | 层级 | 显示形式 |
|---|---|---|
| 研究项名称 | L1 | H2 标题 |
| 研究目标 / 协作说明 | L1 | 正文 |
| 状态（活跃 / 归档 / 回收站） | L1 | 状态徽章 |
| **引用数据集（名字 + 是否最新版本）** | L1 | mount tag 列表 |
| **总被试数（聚合）** | L1 | 大数字 |
| **配置的工作流数 + 状态** | L1 | 简述 |
| **最近活动一句话** | L1 | "2 小时前 跑完 ERP 分析" |
| 协作者列表 | L2 | 头像组 |
| 我的角色 + 权限 | L2 | |
| 创建时间 / 最近更新 | L2 | |
| 研究项 ID | **L3** | TechnicalFold |
| 存储配额 / 已用 | **L2/L3** | 仅在快满时弹 L1 提示 |
| 访问范围 / 状态枚举字符串 | **L3** | TechnicalFold |

### 4.3 工作流 / 执行项字段

| 字段 | 层级 | 显示形式 |
|---|---|---|
| 工作流名称 | L1 | 卡片标题 |
| **流程步骤可视化**（"导入 → 滤波 → 分段 → ICA → ERP"） | L1 | 进度条 |
| **当前进度**（"5/8 名被试处理中"） | L1 | 进度文字 |
| 预估剩余时间 | L1 | "还需 2 分钟" |
| 失败 / 等确认告警 | L1 | 红色 / 橙色横幅 |
| 历史运行列表 | L2 | 时间线 |
| 节点参数详情 | L2 | "高级配置 ▾" 折叠 |
| 运行模式（trial / analysis） | L2 | 短标签 |
| Execution #seq / job_id | **L3** | TechnicalFold |
| Manifest / Lineage / Artifact 内部数据 | **L3** | TechnicalFold |

### 4.4 派生数据 / 结果字段

| 字段 | 层级 | 显示形式 |
|---|---|---|
| **结果类型**（ERP/PSD/时频图等） | L1 | 图标 + 类型名 |
| **缩略图预览** | L1 | 图片 |
| **关联被试 / 条件** | L1 | "sub-01 · 闭眼" |
| 生成时间 | L1 | "2 小时前" |
| 来自哪个流程的第几次运行 | L1 | "ERP 分析 第 3 次运行" |
| 保留策略 | L2 | "固定 / 临时" |

| data_type / retention_status 内部枚举 | **L3** | TechnicalFold |

## 5. 统一设计语言

### 5.1 色彩（直接用 `style.css` 的 CSS 变量，不要 hardcode）

下表值已对齐 2026-06-05 Steel 钢蓝主题迁移后的 `src/style.css`（迁移只降饱和换肤，**类名 / 变量名 / 交互一律不变**）：

| 用途 | 变量 | 值（Steel） | 例 |
|---|---|---|---|
| 主色 | `var(--c-primary)` | `#3F5E8F` | 主按钮、链接、强调 |
| 主色 hover | `var(--c-primary-hover)` | `#344E78` | 按钮 hover |
| 主色变体 | `var(--c-primary-soft)` | `#E9EEF6` | 按钮 hover 背景、轻量高亮 |
| 强调点缀 | `var(--c-accent)` | `#5E7BA8` | 渐变副色、二级强调 |
| 成功 / 就绪 | `var(--c-success)` | `#4F8A6B` | "已就绪""已发布" |
| 警告 / 进行中 | `var(--c-warning)` | `#B07F33` | "运行中""审核中""草稿" |
| 错误 / 高危 | `var(--c-danger)` | `#B0544C` | "失败""撤回""紧急下架" |
| 主文字 | `var(--c-text)` | `#20293B` | 标题、强调 |
| 次要文字 | `var(--c-text-2)` | `#51607A` | 描述、副标题 |
| 灰白文字 | `var(--c-text-3)` | `#79859A` | 辅助、占位 |
| 卡片背景 | `var(--c-surface)` | `#FFFFFF` | |
| 页面背景 | `var(--c-bg-soft)` | `#F4F6F9` | |
| 卡片轻色背景 | `var(--c-bg-tint)` | `#EAEEF4` | |
| 边框 | `var(--c-border)` | `#E4E9F1` | |

**规则**：新组件 CSS 全部用 `var()` 引用，**不要照抄上表 hex**（换肤时只改 `style.css` 令牌，照抄会脱钩）；老组件不强制重构（按需迁移）。

### 5.2 字体层级

颜色统一用令牌，不要照抄旧 hex（下表括号是迁移前旧值，现以 `var()` 为准）：

| 用途 | 大小/字重/颜色 |
|---|---|
| H1 页面标题 | 24px / 700 / `var(--c-text)` |
| H2 区块标题 | 18px / 700 / `var(--c-text)` |
| H3 卡片标题 | 15px / 700 / `var(--c-text)` |
| 正文 | 14px / 400 / `var(--c-text-2)` |
| 辅助文字 | 12px / 400 / `var(--c-text-3)` |
| **核心指标大数** | **32px / 700 / `var(--c-text)`** |

### 5.3 间距（8px 网格）

| 用途 | 值 |
|---|---|
| 相关元素 | 4px |
| 卡片内元素 | 8px |
| 卡片内 section | 16px |
| 卡片之间 | 24px |
| 页面区域之间 | 32px |

### 5.4 卡片基线

```css
border-radius: 10px;
border: 1px solid var(--c-border);
background: var(--c-surface);
padding: 16px 20px;
transition: box-shadow 0.2s;
&:hover { box-shadow: 0 4px 16px rgba(15, 23, 42, 0.08); }
```

### 5.5 状态徽章（Pill）

```css
border-radius: 999px;
padding: 4px 10px;
font-size: 12px;
font-weight: 700;
```

### 5.6 业务图标（emoji 用法）

- 📁 数据集 · 🔬 研究项 · ⚙️ 流程 · 📊 结果
- 👥 被试 · 📋 任务 · ⏱ 时长 · 📅 时间
- ⚠️ 警示 · ✅ 完成 · ⏳ 进行中

emoji 仅用于"业务对象图标"，UI 控件图标仍用 lucide / heroicons 风格的 AppIcon。

## 8. TechnicalFold 组件契约

```vue
<TechnicalFold title="技术信息" hint="ID / 存储路径等" :default-open="false">
  <dl>
    <div><dt>数据集编码</dt><dd>{{ asset.code }}</dd></div>
    <div><dt>UUID</dt><dd>{{ asset.id }}</dd></div>
    ...
  </dl>
</TechnicalFold>
```

`components/TechnicalFold.vue` 的 props（以代码为准）：

| prop | 说明 |
|---|---|
| `title` | 折叠区标题，可自定义（"调试信息" / "高级配置" / "原始数据" 等） |
| `hint` | 标题旁的灰色提示（`DatasetsPage` / `ResultsPage` 都在用） |
| `defaultOpen` | 是否默认展开，默认 `false`（折叠） |

- 默认折叠
- summary 用灰色、12px、虚线分隔

## 9. 反例（违反原则的写法）

| 反例 | 问题 | 改成 |
|---|---|---|
| `<span>Dataset Assets 8</span>` | 中英文混排，"Dataset Assets" 是内部对象名 | "数据集 8 个" |
| 直接显示 `elys:dataset/uuid/v1.0.0` 字符串 | 用户不需要看 DOI 字符串具体值 | "已注册学术 DOI [复制]" 按钮 |
| `<span>Execution #3 completed</span>` | 编号 + 英文状态 | "ERP 分析 第 3 次运行 已完成" |
| "文件总数 48 / BIDS 视图 20 / FIF 8" 并列展示 | 全是平台内部统计，用户不关心 | 全部折进 TechnicalFold |
| `<select><option>working</option></select>` | 暴露后端状态枚举 | 改为中文 "草稿 / 已发布 / 已撤回" |
