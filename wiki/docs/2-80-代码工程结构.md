## 7. 启动与构建

| 任务 | 命令 |
|---|---|
| 后端 dev | `uvicorn app.main:app --reload --host 127.0.0.1 --port 8000` |
| 前端 dev | `cd frontend/elys-web && npm run dev` |
| 前端 build | `cd frontend/elys-web && npm run build`（输出 `dist/`） |
| 后端依赖 | `pip install -r backend/requirements.txt` |
| 前端依赖 | `cd frontend/elys-web && npm install` |
| 一键部署 | `pwsh elys_project/deploy/deploy_remote.ps1` |
| 文档站点 | `pwsh wiki/deploy_docs.ps1` |
