## 2026-05-31 · UI 信息分级原则与领域语言落档

**决策方向**：基于用户截图反馈（DatasetsPage 暴露文件总数 / BIDS 视图 / FIF 数量 / 内部 ID / DOI 字符串等），确立"L1/L2/L3 信息分级"和"领域语言"两大原则，所有页面 UI 都按此分级取舍。

## 2026-05-31 · 数据集生命周期与发布机制设计

**决策方向**：重构数据集模型，引入 draft / published / withdrawn 生命周期，把 `datasets` 表去 study 化、改名 `recordings` 并直接归属 `DatasetAsset`。整体方案分 6 阶段渐进迁移。

**文档层**：新增 [3-25 数据集生命周期与发布机制](3-25-数据集生命周期与发布机制.md)（含状态机、Schema 变更清单、4 项关键决策、6 阶段迁移路线）。

**4 项关键决策**：

- DEC-A 撤回机制：owner 申请 + 管理员审核，**withdrawn 为终态**，要继续工作必须开新版本；超级管理员有紧急下架通道
- DEC-B 主 Study 在 published 后保留作"出身记录"，外键 `ON DELETE SET NULL`
- DEC-C `version_label` 强制 SemVer `x.y.z`，major=实验设计变更 / minor=加被试 / patch=元数据修正
- DEC-D 紧急下架仅限超级管理员，跳过审核但必须事后补审计

**设计依据**：OpenNeuro / Zenodo / PhysioNet / OSF / Dryad 公开数据平台调研。采纳 Zenodo 双 DOI（Concept + Version）+ 强制墓碑 + PhysioNet SemVer + 避开 OpenNeuro 自助删除坑。

## 2026-05-24 · 数据库 schema 拆分为 6 文件、删除 migrations、停用 Alembic

**决策方向**：把单文件 713 行的 `database/schema/00_current_schema.sql` 拆为 6 个按业务模块组织的 SQL 文件；删除 `database/migrations/`；停用 `backend/alembic/`；升级线上库统一改为 **DROP DATABASE + 重建**。

**Schema 拆分（6 文件）**：`01_auth.sql`（认证授权）、`02_studies.sql`（研究项骨架）、`03_datasets.sql`（数据集与文件）、`04_pipelines.sql`（工作流核心）、`05_derived.sql`（派生数据与 Execution I/O）、`06_async.sql`（异步任务）。

**文档层**：更新 [3-00 数据库设计总览](3-00-数据库设计总览.md)（事实源指向、6 文件分组表、当前落地快照、ER 图）；新增 [3-05 数据库模块与功能关联](3-05-数据库模块与功能关联.md)（6 模块详解、模块间数据流、跨模块查询场景、ORM 映射对照）。

**Why**：项目数据量小、schema 迭代频繁、团队对 Alembic 不熟悉，"schema 文件 + 增量 migration + Alembic 三套并存"易漂移。简化为"schema 文件作为单一事实来源 + DROP/重建升级"路径。

## 2026-05-24 · Project → Study 全栈彻底改名

**决策方向**：原内部命名 `Project` 全栈改为 `Study`。除少数 docstring 历史说明外，全栈无残留。

**改名涉及（按层）**：

- 数据库：表 / 列 / 函数 / 计数表 / Schema 文件 / 种子权限 / 索引名
- 后端 ORM / Schemas / Services / Routers / Tests / Pipeline / Tasks / Storage URI scheme（`project://` → `study://`）
- 前端类型 / API / Vue 组件 / Router
- 物理目录：`/mnt/elys_data/projects/` → `/mnt/elys_data/studies/`
- 环境变量：`PROJECTS_DIR` → `STUDIES_DIR`
- 字段：`bids_root` → `data_root`
- 审计表：`StudyAuditEvent` 合并到 `AuditEvent`，加 `snapshot JSONB` 列

**Why**：用户命名原则——"统一，彻底"。降低长期维护成本和新人认知负担。
