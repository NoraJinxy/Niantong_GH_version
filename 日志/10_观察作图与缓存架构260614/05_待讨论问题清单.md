## 0. 当前冲刺定调

**先做 ERP / 时域作图。** 一句关键发现先说：**elys 后端的时域数据层已经就绪**——`build_timeseries`（[`timeseries.py`](../../elys_project/backend/app/pipeline/timeseries.py)）已支持 **5 种数据形态**：`raw / filtered_raw / ica_cleaned`（连续 channel×time）、`epochs`（channel×time×epoch，带段选择 + 事件标签）、`evoked`（ERP，选 condition），且自带时间窗 / 段选择 / 通道与采样点下采样。**所以 ERP/时域冲刺的瓶颈在前端渲染，不在后端**（你 D1 要的形态后端都能吐）。

## 2. 当前冲刺：ERP / 时域作图（优先解决，按序）

### 2.1 ✅ 数据层已就绪（不是瓶颈）

| 形态 | data_type | 端点行为 | 段语义 |
|---|---|---|---|
| 连续 channel×time | `raw` / `filtered_raw` / `ica_cleaned` | 时间窗 tmin/tmax + 下采样 | 无段 |
| 分段 channel×time×epoch | `epochs` | 选 epoch（`index`）+ 时间窗 | `n_segments`=试次数，`segment_kind=epoch`，含事件标签 |
| ERP channel×time | `evoked` | 选 condition（`index`）+ 时间窗 | `segment_options`=条件列表 |

端点：`GET /studies/{id}/outputs/{dd}/timeseries`（[`study_outputs.py:500`](../../elys_project/backend/app/routers/study_outputs.py) → [`build_timeseries`](../../elys_project/backend/app/pipeline/timeseries.py)）。**结论：前端按 `data_type` 渲染同一套时域图即可，数据契约后端已统一。**

### 2.2 ✅ 多因素叠加/排版 → 定为「三因素 facet」（已定，见 [`06` §6-A](./06_时域看图P1实施方案.md)）

因素 = {数据集 / 段(evoked 条件、epochs 试次) / 通道}，任选两因素做 m×N 子图网格、第三因素格内叠加(overlay/spread)，可自由切换（参考 LetsWave / Niantong）。trace 身份 = 数据集×段×通道；多段叠加 = 前端并发取 N 段(index)。**P1 先单数据集 + {段,通道}，多数据集对比快随。**

### 2.3 ✅ 曲线分类色板 → 定为「elys 烙印版」（已定）

默认 `--c-cat-1..8` = #3F5E8F/#B0544C/#4F8A6B/#B07F33/#5E7BA8/#7B5EA8/#2F8A86/#8A6E5E（长在 elys 品牌色上）；下拉内置 NPG / Wong 可切；>8 条用 `channelColor(i)` 黄金角兜底。

### 2.4 ✅ 段控件 → 按默认（已定 b/d）

epochs：翻页器 + 试次范围；evoked：条件多选（接 facet 段叠加）；raw：时间窗导航。**形态不设手动开关**，按打开 output 的 `data_type` 自适应。

### 2.5 ✅ 缓存 → 三级一起上（已定 2.5）

三级瀑布（内存 → IndexedDB → 网络）**P1 就做满**（为 TFR 铺路）；key = `studyId::outputId::seg::窗::picks::maxPoints`（二期对齐 trace_code）；外加**缓存调试浮层**（dev 显示、发布隐藏）。详见 [`06` §5](./06_时域看图P1实施方案.md)。

### 2.6 ✅ 区间统计 / 选区 → 进 P1（已定 2.6）

框选区间 + 右栏区间统计（均值/峰值/峰值潜伏期）纳入 P1。

### 冲刺落地节奏 → 见 [`06` §7](./06_时域看图P1实施方案.md)

任务 A(抽 composable)→G(后端二进制端点)→B(uPlot 宿主)→C(facet+多trace+配色)→D(三级缓存+调试浮层)→E(选区统计+入口收敛)→F(验收真机)。**A 与 G 可并行，A 纯前端最安全、可立即开工。**
