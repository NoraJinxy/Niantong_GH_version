## 0. 一句话目标

把 Niantong 的**时域（ERP/Raw 波形）、频域（PSD/频谱）、时频（TFR/CWT 热图）**三个观察视图，**行为与布局极大吸收、配色样式换 elys**地搬进 elys。三者合一篇的根据是：**它们是同一件事的不同呈现维度**——时域、频域都是「一维曲线」（只是横轴从时间换成频率），时频只是把这条曲线**沿第二维铺开成二维热图**。一套坐标/游标/选区/地形图联动骨架贯穿三者。

## 1. 背景与设计纲领

### 1.1 核心心智：1D 曲线族 → 2D 提升（这是合篇的根据）

| 视图 | 横轴 | 纵轴 / 第二维 | 图元 | 渲染技术 | 「降一维」切片 |
|---|---|---|---|---|---|
| **时域** ERP/Raw | 时间 | 幅值 µV（多通道堆叠） | **1D 折线** | uPlot（Canvas） | — |
| **频域** PSD/频谱 | 频率 | 功率 | **1D 曲线** | **uPlot（与时域同引擎）** | — |
| **时频** TFR/CWT | 时间 | **频率（第二维）**，功率用**颜色** | **2D 热图** | Canvas `ImageData` + uPlot 外壳 | 固定某时刻 → 一条**频谱(1D)**；固定某频率 → 一条**时间功率曲线(1D)** |

一句话：**时频 = 频域曲线沿时间轴展开成的「电影」**；反过来，对时频图做一条竖切/横切，就退回成时域或频域的 1D 曲线。三者共享：频段（δ/θ/α/β/γ）概念、「游标点 → 弹该处头皮地形图」联动、轴/缩放/选区/facet 网格骨架。Niantong 里它们也确实复用同一套 `tc-*`/`erp-*` 布局类、同一个 Topography 渲染器、同一套游标节流逻辑——所以放一页，强调「同源骨架 + 三种图元」。

> 黑话铺垫：PSD（power spectral density，功率谱密度）= 信号里各频率成分各占多少能量，丢掉时间维压成一条曲线；TFR（time-frequency representation）/ CWT（continuous wavelet transform，连续小波变换）= 一张「时间×频率」热力图，颜色=该时刻该频率的能量，保留时间维。

### 1.2 吸收原版什么 / 不吸收什么

| 维度 | 处置 | 说明 |
|---|---|---|
| 画图**行为功能** | **极大吸收** | 时域三大交互（缩放/选通道/选区）+ 游标→地形图节流联动 + 频谱抽稀/单调样条/统计频带 + TFR 的 ImageData 贴图/uPlot 外壳/邻道预取 + facet 行列布局 |
| **页面布局**（左控制 / 中图 facet / 底地形 / 右统计） | **极大吸收** | 三视图布局同构，左控制三件套（数据集/事件/通道）+ 统计范围 + 绘图布局行列原样搬，分隔条可拖 |
| 渲染**实现** | **重写** | 时域与频域**同走 uPlot 宿主**（1D 曲线统一，详见 §5.1）、TFR Canvas ImageData+uPlot 外壳；不照搬「全局 `<script>` + `window.*`」加载法，一律 npm + Vite + 组件 |
| **配色 / 字体 / 图标 / 控件样式** | **走 elys 主体** | `var(--c-*)` token、`var(--ff-sans/mono)`、Lucide 线性图标；jet 色标、通道色、频段色都换 elys 调色 |
| **领域语言** | **走 elys** | 不出现 `data_id / session_id / picks`，UI 说「通道/时间窗/频段/条件」 |

### 1.4 persona 与配色口径

受众=医生/心理/神经科学家，纲领=让脑电处理**显得简单 fancy 而非复杂**：

- 默认就给「有意义的默认态」（如 α 频段已选 + 该频段地形图），别让用户面对空图自己配。
- 高级手势（Shift 滚轮缩 Y）藏 tooltip/提示条，不堆按钮。
- jet 配色对临床读者偏花哨刺眼，提供 elys 调的「学术红蓝 RdBu / viridis」作默认候选。
- 文案领域化：「时间窗/频段/叠加·排列/实时地形图/平均地形图」，不暴露 annotation/picks/sfreq。

### 5.1 渲染技术选型（对齐 [`./00`](./00_总览与架构决策.md) 两平面）

| 图元 | 技术 | 理由 |
|---|---|---|
| 时域多通道波形（宿主） | **uPlot (Canvas)** | 实时探索面：万点级高刷平移缩放 |
| 竖游标/彩点/坏段块/选区/事件线 | uPlot `draw` hook 自绘（Canvas） | 与波形同坐标系，每帧重画 |
| 频谱曲线 + 频段背景 + 统计带 | **uPlot（与时域同一引擎）** + spline/自定义 paths（可复刻单调三次样条防假峰）+ ≤4096 抽稀 + 频段背景走 draw 钩子 | 1D 曲线与时域统一渲染/交互/缓存，少一套代码；矢量留 FigureSpec 二期 |
| TFR 热图 | **Canvas `ImageData` 烤整张 → uPlot 背景贴图** | 见 §5.2 |
| TFR 轴/网格/缩放 | **uPlot** 外壳（`hooks.draw` 贴热图） | 海量格子，uPlot 负责轴与交互 |
| 实时/平均/频段/时频点地形图 | Canvas ImageData + IDW + d3-contour | 见 [`./04`](./04_地形图与ICA成分页.md)，本页只喂数据 |
| 论文定版出图 | SVG/D3 + FigureSpec | 见 [`./00`](./00_总览与架构决策.md)；探索结果「送作图」时转译 |

> 为什么时域不沿用 `WaveformDetailPage` 的纯 SVG path：通道多/点多/高频缩放时 SVG DOM 重排会卡；uPlot 走 Canvas 命令式批绘流畅。**频域点虽少，也统一走 uPlot**（同一套轴/游标/选区/缩放，少维护一套渲染器）——「按几何分渲染器，不按视图分」。SVG 只留给定版出图（FigureSpec 二期，独立产矢量，不靠序列化探索图）。

### 5.2 为什么 TFR 用「ImageData 贴图」而非逐格 fillRect（替换 elys 反模式）

elys 现 `TfrPage.vue` 用 `v-for` 生成几千个 `<rect>`（L107-117），100 freq×300 time = 3 万节点 → Vue diff 与浏览器布局卡死且无法缩放。吸收原版三步：

1. **一次性烤图**：矩阵每值经色标写进 `ImageData`（一格=一像素），`putImageData` 到 `nTimes×nFreqs` 离屏 canvas（[`buildHeatmapImage` L1740](../../Niantong-eeg-analysis/frontend/js/ui/Plot_Frequency_v2.js)）。O(格数) 一次、无 DOM。
2. **缩放靠 drawImage 重采样**：按 uPlot 当前 x/y scale 裁源 canvas 子矩形拉伸（[`drawCurrentHeatmapToUplot` L1880](../../Niantong-eeg-analysis/frontend/js/ui/Plot_Frequency_v2.js)，`imageSmoothingEnabled=false`）。只搬像素不重算颜色。
3. **uPlot 只管坐标**：series 透明、cursor/legend 关，热图经 `plugins:[{hooks:{draw}}]` 贴入（L1955）。
> 频轴翻转必保留：`sourceFreqIdx=height-1-y`（L1778），否则上下颠倒。

### 5.5 Vue 集成要点（命令式库包成组件）

- **命令式 DOM 库**：uPlot/离屏 canvas 用 template ref，`onMounted` 建（`new uPlot` / 建离屏 canvas / 装 draw 钩子），`onUnmounted` 销（`chart.destroy()` + 断 ResizeObserver + 解绑 window 事件）。
- **大 TypedArray 别进响应式**：`Float64Array times` / `Float32Array data` / 离屏 canvas / uPlot 实例 / slice 缓存 Map 一律 `shallowRef`/`markRaw`/`toRaw`，否则 Vue Proxy 逐元素拦截、几十万点拖垮。
- **resize**：SVG 谱图 rAF 节流后**重算重绘**（`resizeSpectrumPlotsToCards` L2091）；TFR/uPlot 调 `setSize()`。
- **节流**：谱游标 28ms、谱地形图 80ms；TFR live topomap rAF + 单飞排队；时域游标→地形图 rAF 合并。

### 5.6 配色 / 样式走 elys

- 全部颜色读 `src/style.css` token：通道色用 elys 分类色板（替原版 `TRACE_COLORS`/`COLORS` 硬编码）；统计带 `--c-primary` 低透明；轴/网格 `--c-border`/`--c-text-3`；等宽数字 `--ff-mono`；频段沿用 PsdPage `bands`（L433-439）。
- TFR 色标抽成可替换 `colormap(norm)=>[r,g,b,a]`，提供 jet/RdBu/viridis/hot，**默认建议 RdBu**（TfrPage `cmap` 下拉已埋点 L44-48）。
- 工具条用 Lucide 线性图标；不搬原版「念析」品牌块与 inline style，统一进 `WorkbenchShell` + `ObserveTabs`。

### 5.7 与 FigureSpec 的关系

本页是**探索面**，默认不产论文图。但**现在就把渲染拆成「可被 FigureSpec 复用的纯渲染器」**：`renderSpectrumPath(spec)→SVG path`、`renderHeatmapImage(matrix,colormap)→canvas`、topomap 渲染器（[`./04`](./04_地形图与ICA成分页.md)）都做成无副作用（入参=数据+主题，出参=可绘制物），二期作图模块直接喂 FigureSpec 复用，避免返工（[`./00` §3.2](./00_总览与架构决策.md)）。点「发送到作图模块」（`ErpPage.vue:216` 已有入口）= 把当前视图序列化成 FigureSpec 快照转译。
