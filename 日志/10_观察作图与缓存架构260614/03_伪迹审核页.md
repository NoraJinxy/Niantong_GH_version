## 0. 一句话目标

把 Niantong 的**伪迹审核**工作流（在多通道波形上框选坏段、点标坏道、一键自动检测、随鼠标刷新的瞬时头皮地形图、底部全程信号概览带）**行为与布局极大吸收**进 elys：渲染层复用 [`./02`](./02_信号作图页.md) 的 `TimeCourseCanvas` 时序宿主，审核交互抽成一个可插拔的 `useArtifactReview` 组合式；配色/字体/图标换成 elys 主体设计，让医生/神经科学家看到的是「干净、领域语言的审核台」而非工程师的示波器。

## 1. 背景与设计纲领

### 1.1 为什么伪迹审核独立成篇

时域观察、频域、时频是「看」——只读呈现信号（见 [`./02`](./02_信号作图页.md)）。伪迹审核是「**审 + 改**」——它是一条完整的**质控工作流**：发现异常 → 标记（坏段/坏道）→ 自动辅助 → 决策落库 → 影响下游。它在 Niantong 里是单文件 5628 行（[`Interact_ArtiRejec.js`](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）的大块，交互密度和「是否能改数据」的语义都远超单纯看图。所以单独成篇。

### 1.2 与信号作图（[`./02`](./02_信号作图页.md)）的关系

伪迹审核**不重画时序宿主**——它复用 `TimeCourseCanvas`（uPlot 多通道波形 + 游标/选区/点击回调），只是把那些回调接到「加坏段 / 标坏道 / 右键菜单 / 自动标记」上，并在 `draw` 钩子里叠加「坏段红块 / 坏道置灰」两个图层。即：

```
时域观察  =  TimeCourseCanvas（裸宿主）
伪迹审核  =  TimeCourseCanvas  +  useArtifactReview（审核交互层）  +  底部 SignalOverviewBand  +  实时地形图
```

> 黑话铺垫：「时序宿主」= 负责画 X=时间、Y=多通道堆叠波形的画布组件；「交互层」= 挂在它上面、响应鼠标手势改业务状态（选区/坏段/坏道）的一组回调，不自己画骨架。

### 1.3 吸收原版什么 / 不吸收什么

| 维度 | 处置 | 说明 |
|---|---|---|
| 审核**交互行为**（框选坏段/点标坏道/右键清段/自动标记/概览带导航） | **极大吸收** | 逐条复刻，含坏段合并、命中容差、rAF 节流 |
| **页面布局**（三栏 + 底概览带 + 左栏坏道坏段管理） | **极大吸收** | 在时域三栏基础上加底部 minimap 与左栏审核面板 |
| 渲染实现 | **重写** | 复用 elys `TimeCourseCanvas`，坏段/坏道绘制注入其 `draw` 钩子 |
| 配色/字体/图标 | **走 elys** | 坏段、坏道用柔和语义色（danger-soft/muted），不要原版刺眼硬红 |
| 自动检测算法 | **吸收（后端）** | `auto_mark_artifacts_mne` 稳健 z-score 逻辑值得照搬到 elys 后端 |

### 1.4 elys 现状（只读）

- **elys 当前无伪迹审核页**；最接近的是 [`WaveformDetailPage.vue`](../../elys_project/frontend/elys-web/src/views/WaveformDetailPage.vue)（真实时域、简陋 SVG），可作宿主交互的起点，但无任何标记/审核能力。
- `ObserveTabs` 无「伪迹/质控」签——本页落地需新增入口（路由或模式开关，见 §5.1 / §8-Q3）。
- 后端：elys 现走 study/output 模型，**无伪迹专用端点**（summary/window/auto-mark 都要新建或决策，见 §4.4）。

### 1.5 persona 与配色口径

- 默认进来是「干净波形 + 一个友好审核工具条」，「自动检测异常」是醒目主按钮（降低门槛），手动标记是次级操作。
- 坏段=`var(--c-danger-soft)` 半透明、坏道=`var(--c-text-3)` 灰；不用原版 `rgba(204,90,113,…)` 硬红。
- 文案领域化：「标记坏段 / 标记坏道 / 自动检测异常 / 清除标记」，不暴露 annotation/picks/sfreq。

### 2.1 框选坏段

- **合并** `mergeBadSegments`（[5152-5163](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）：排序后相邻/重叠区间并起来；`addBadSegment` 调它，幂等（重复加同段不变）。
- **绘制**：`createInteractionPlugin().draw` 遍历 `getBadSegments()`，`valToPos` 时间转像素，画 `rgba(204,90,113,0.18)` 半透明红块（[`VisualFactors_TimeCourse.js:1436-1453`](../../Niantong-eeg-analysis/frontend/js/ui/VisualFactors_TimeCourse.js)）。
- 选区来源是 uPlot `setSelect`（宽<8px 忽略，600ms 去抖，见 [`./02` §2.1C](./02_信号作图页.md)）。

### 2.2 标坏道

- 点波形 → `findNearestChannelName`（[5225-5242](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）取最近道，命中容差 `BAD_CHANNEL_HIT_TOLERANCE`（[5241](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)，超出不命中）。
- `toggleBadChannel` 增删坏道 Set → `getChannelStroke` 命中返 `#b9c0c7` 灰、tick 加 `*` 后缀（[5184-5185](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）→ redraw。
- 也可双击地形图上的电极点标坏道（见 [`./04`](./04_地形图与ICA成分页.md)）。

### 2.3 右键清段 / 上下文菜单

右键命中已有段 → 清该段；右键空白 → 弹坏段上下文菜单（contextmenu [1654-1689](../../Niantong-eeg-analysis/frontend/js/ui/VisualFactors_TimeCourse.js)）。wiki 评价「右键清选区不直观」（[`03-前端页面-13:119-139`](../../Niantong-eeg-analysis/docs/wiki/03-前端页面-13-时域观察交互行为.md)）——elys 顺手做掉（加 Esc/可见删除按钮）。

### 2.4 自动标记

`autoMarkArtifactSuggestions`（[5271-5329](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）：调后端 → `bad_channels` 并入 Set、`bad_segments` 合并 → 重绘 + 刷地形图；期间禁按钮、文案「自动检测中…」。后端算法见 §4.3。

### 2.5 实时 / 区间平均地形图联动

- 游标驱动 `onPointerMove → scheduleTopomapUpdate(idx)`（[3652 / 5339](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）。
- `scheduleTopomapUpdate`（[5137-5143](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）：`requestAnimationFrame` 合并高频鼠标事件，只保留 `pendingIndex`，每帧最多渲一次——**性能关键，必须照搬**。
- 「实时地形图」=当前时刻全通道电位插值；「区间平均地形图」=选区 `[start,stop]` 各通道均值插值。共用 [`./04`](./04_地形图与ICA成分页.md) 渲染器，喂的列不同（瞬时一列 vs 区间均值）。

### 2.6 底部信号概览带（minimap）

全程信号包络缩略图 + 坏段标记，点/拖可跳窗。数据由后端 `_build_signal_overview` 给（见 §4.1）。

## 4. 数据接口

伪迹审核要在接近原始采样率看波形、要快速平移大窗，JSON 太重。Niantong 用**二进制 + SHA1 分块增量**，在 [`Interact_ArtiRejc.py`](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)：

### 4.1 `GET /api/artifact-interact/summary`（[307-348](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）

一次性元信息：`sfreq / n_channels / n_times / tmin / tmax / ch_names / standard_channel_positions`（地形图要的 2D 坐标）+ `markers`（事件标记，从 annotations 或 `find_events`，[217-272](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）+ **`overview_times / overview_signal_uv`**（概览带包络）。

概览包络 `_build_signal_overview`（[275-304](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）：取前 `OVERVIEW_MAX_CHANNELS=12` 道 EEG，降到 `OVERVIEW_MAX_POINTS=1400` 点，减中位数后取**逐样本跨通道中位绝对值**当包络，再 7 点滑动平均——把全程压成一条「这段有多吵」的缩略曲线。

### 4.2 `GET /api/artifact-interact/window`（[351-459](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）

取某时间窗波形，返回 `application/octet-stream`：

- 参数 `start/stop`(秒)/`picks`(逗号通道名)；请求头 `X-EEG-Known-Hashes`（前端已缓存的块哈希）。
- **渲染降采样上限 `MAX_RENDER_SFREQ=250.0`**（[26](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）：再高也按 250Hz 等距抽点（[382-390](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)），人眼+屏幕分辨不出更多。
- **分块增量**：窗口按 `HASH_CHUNK_SECONDS=10s` 切块，每块算 SHA1（含文件签名+通道+数据，[208-214](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）；返回头 `X-EEG-Chunk-Manifest`（每块 `{h,s,e,n,i}`，`i=1`=新块）；**只有新块的二进制进 body**（[420-438](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）——平移到重叠窗口时重叠块前端已有、不重传。
- 头还回 `X-EEG-Sfreq/N-Channels/N-Times/Tmin/Tmax/Ch-Names`（[439-457](../../Niantong-eeg-analysis/backend/Interact_ArtiRejc.py)）；块布局 `times(float64) || data(float32, C-order)`。

### 4.3 自动标记后端（`auto_mark_artifacts_mne`，[modu_process.py:1482-1591](../../Niantong-eeg-analysis/backend/modu_process.py)）

- **坏道**：每道算 `std / 峰峰值ptp / 高频噪声(diff std)` 三指标，各取**稳健 z-score**（`_robust_z_scores`=中位数/MAD，[1371-1385](../../Niantong-eeg-analysis/backend/modu_process.py)），取最大；超 `channel_z_threshold=3.5` 判坏，封顶 `max_bad_channels=12`（[1509-1525](../../Niantong-eeg-analysis/backend/modu_process.py)）。
- **坏段**：优先 MNE `annotate_amplitude`（peak=200µV / flat=0.5µV），回退「跨通道绝对峰值 ≥ 阈值」布尔掩码转区间（[1530-1562](../../Niantong-eeg-analysis/backend/modu_process.py)）；合并相邻段（gap≤0.05s）。
- 返回 `{bad_channels[], bad_segments[{start,stop,duration,description}], channel_metrics{}, n_bad_channels, n_bad_segments}`（[1585-1591](../../Niantong-eeg-analysis/backend/modu_process.py)）。
- 稳健 z-score 大白话：用中位数和「中位绝对偏差」代替均值和标准差，一两个超大坏道不会把判坏门槛自己抬高。

### 4.4 elys 接口决策（待 §8 拍板）

elys 是 study/output 模型（无 session_id）、JSON 下采样窗口。伪迹页两大后端决策：(1) 是否把二进制分块协议搬过来对齐 `outputs/{dd}/window`（§8-Q1）；(2) 坏段/坏道写回哪里、自动标记端点是否落地（§8-Q2，关乎「能不能改数据」）。短期 P1 先用现有 JSON 窗口顶；二进制大窗 P3 再上。

## 5. elys 落地设计

### 5.1 复用 TimeCourseCanvas + useArtifactReview

`useArtifactReview()` 组合式，持有 `badSegments / badChannels` 响应式状态，对外给 `TimeCourseCanvas`（[`./02` §5.3](./02_信号作图页.md)）的回调实现：

- `onRangeSelect → addBadSegment`（归一+合并，抄 `mergeBadSegments` [5152-5163](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）。
- `onChannelClick → toggleBadChannel`（坏道 Set 增删 → 重绘置灰）。
- `onSegmentContext → 右键菜单`；`onRangeClear → 删该段`；`Esc → 清当前选区`。
- `autoMark() → 调自动检测端点`，并入结果 → 重绘。
- 坏段红块、坏道置灰两个**绘制**注入 `TimeCourseCanvas` 的 `draw` 钩子（坏段块抄 [1436-1453](../../Niantong-eeg-analysis/frontend/js/ui/VisualFactors_TimeCourse.js)、坏道 stroke 抄 [5184](../../Niantong-eeg-analysis/frontend/js/ui/Interact_ArtiRejec.js)）。

「时域观察」与「伪迹审核」=**同一 `TimeCourseCanvas` + 是否挂 `useArtifactReview`**。入口形态（一页两模式 vs 独立路由）见 §8-Q3。

### 5.2 Vue 组件树

```
ArtifactReviewPage.vue（或 /observe/erp 的「审核模式」）
├─ aside  ArtifactSidePanel.vue       左栏：坏道列表 / 坏段列表 / [自动检测异常] / [清空] / 阈值
├─ main
│   ├─ TimeCourseToolbar.vue          复用 ./02，加「审核模式」状态

│   │     └─ (插槽) TopomapViewport    实时 + 区间平均地形图（./04 组件）

└─ (组合式) useArtifactReview()        坏段/坏道状态 + 回调 + 自动标记 + 落库
```

### 5.3 「能改数据」边界（★ 本页最关键设计点，阻塞 🔴）

伪迹审核区别于纯看图的核心在于「**结果要落库、要影响下游**」。在 elys 调试期模型里要定：手标/自动标的坏段坏道**写回哪里**——

- 选项 A：写成 study output 的 `annotations`（轻、贴 MNE 习惯）；
- 选项 B：新建「质控标注」实体（重、可独立版本化/审计）；
- 选项 C：作为一个「伪迹剔除」节点的参数（落进流水线 trace_code，天然进缓存与溯源）。

牵涉 memory `pending-design-decisions` 的 StudyOutput 生命周期、`dataset-study-domain-model`。**定前本页只做「只看 + 前端临时标记」，不落库**（见 §7 P1/P2）。

### 5.4 配色 / 样式走 elys

坏段=`var(--c-danger-soft)` 半透明、坏道=`var(--c-text-3)` 灰、概览带坏段标记=同 danger；工具条 Lucide 图标；文案领域化。不搬原版硬红与品牌块。

## 6. 缓存接入（原理见 [`./01`](./01_前后台多级缓存机制.md)）

| 数据 | 前端层 | cache key |
|---|---|---|
| 窗口波形（大窗高刷） | L1 内存 + **L3 二进制 SHA1 分块**（平移到重叠窗只取新块） | 块哈希 = `fileSig+picks+chunkTimes+chunkData`(SHA1)，请求带 `X-EEG-Known-Hashes` |
| 信号概览带 | 「一次拉、长期留」整段缓存（不进窗口 LRU） | `outputId`（概览不随窗口变） |
| 实时/平均地形图 | 地形图位图缓存 | `outputId+(timeIdx\|rangeKey)+colormap`（细节见 [`./04`](./04_地形图与ICA成分页.md)） |

要点：分块增量是「窗口缓存」的下沉版——L1 命中整窗直接画，未命中但块复用走 L3 只补差量；typed array 用 `markRaw`/`shallowRef`。

## 7. 分阶段开发计划

### P1 · 只读审核台（不落库）🆕
复用 `TimeCourseCanvas` + `useArtifactReview`（前端临时态）；框选坏段、点标坏道、右键/Esc 清段、坏段红块/坏道置灰绘制；接现有 JSON 窗口端点。**交付**：能在真实波形上手动标记（仅前端态）。**验收**：坏段红块持久、坏道置灰正确。

### P2 · 地形图联动 + 自动检测 🆕 / ⏸
游标→实时地形图（rAF 合并）、选区→平均地形图（接 [`./04`](./04_地形图与ICA成分页.md)）；底部 `SignalOverviewBand`（拉 summary 包络，或前端降级估算）；「自动检测异常」接自动标记端点（⏸ 阻塞 §8-Q2）。**验收**：自动标记结果并入、地形图跟随。
