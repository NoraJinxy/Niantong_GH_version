### 1.2 timeseries 数据契约（已核实）

五形态返回**同一套 dict**（[`types/index.ts:977-1007`](../../elys_project/frontend/elys-web/src/types/index.ts)）：`data_type / sfreq / tmin / tmax / total_duration / available_tmin / available_tmax / n_segments / segment_index / segment_label / segment_kind / segment_options / n_channels_total / ch_names_all / times / channels[{name,values}]`。

| 形态 | times | n_segments / segment_kind | 段选择 |
|---|---|---|---|
| raw/filtered_raw/ica_cleaned | 绝对秒 | None / None | 时间窗 |
| epochs | 相对秒 | epoch 数 / `"epoch"` | `index` 选 epoch；`segment_label`=事件名 |
| evoked | 相对秒 | condition 数 / `"condition"` | `index` 选条件；`segment_options`=条件名列表 |

**要处理的点（本轮已收敛）：**
1. ⚠️ **单位是伏特 V，不是 µV**（契约无 `unit`）→ **二进制端点的头里带 `unit` 并直接发 µV**（§5），前端不再硬乘 1e6；旧 JSON 路径过渡期前端 ×1e6 兜。
2. ✅ **t=0 零线 / 事件标记本模块不画**（本轮决定）——带 trigger 的原始数据观察交给未来专门模块。`zeroX`/events 全部移出 P1 范围。
3. **多段叠加 = 前端发 N 次请求**（端点单次 1 段，用 `index` 选；`n_segments` 已知）——facet 的「段」因素叠加时按此并发取。
4. 其它：`max_points` 默认 2000、可到 8000（[`study_outputs.py:500-538`](../../elys_project/backend/app/routers/study_outputs.py)）；`epochs` 的 `segment_options=None`（用 index+n_segments 翻页）；无 montage 坐标（与 P1 无关）。

## 2. P1 目标形态

一个 `/observe/waveform` 页，打开任一时域 output 即：

- **uPlot 多通道波形**：堆叠(spread)/叠加(overlay) 两种格内呈现；滚轮缩 X、Shift 滚轮缩 Y、双击复位、框选缩放、悬停十字游标+读数。
- **形态自适应**（LetsWave 式）：raw→连续窗口；epochs→试次翻页(index+n_segments)；evoked→条件选择。
- **三因素 facet 布局**（§6-A）：{数据集 / 段 / 通道} 任选两因素做 m×N 子图网格、第三因素格内叠加，可自由切换。
- **二进制传输**：波形走 float32 二进制（§5），头里带 unit/sfreq/通道等。
- **三级缓存**（内存→IndexedDB→网络）+ **缓存调试浮层**（dev 显示，发布隐藏）。
- **区间选区 + 区间统计**（均值/峰值/峰值潜伏期）。
- **配色 = elys 烙印版** + >8 条黄金角兜底。

## 5. 数据流（二进制 + 三级缓存）

```
facet 指派 → useFacetLayout 算出要哪些 (dataset, segment) 组合 + 网格结构
  → 对每个组合 usePlotCache.get(key)：
      key = studyId::outputId::segIndex::round(tmin,tmax)::picksHash::maxPoints
      ① 内存 Map 命中 → 直返
      ② IndexedDB(PersistentPlotDataCache) 命中 → 回填内存 → 返
      ③ 全 miss → GET .../timeseries?format=binary  (二进制：magic + JSON头{unit,sfreq,n_ch,n_times,ch_names,segment...} + float32 body)
            → (payload 小则主线程解码；大则 Web Worker 解码——TFR/全分辨率时启用)
            → 头里 unit 决定缩放（后端直接发 µV → 前端不再 ×1e6）
            → 回填内存 + 异步回填 IndexedDB
  → useMultiTrace 按 facet 把各组合的通道拼成每格 AlignedData（叠加因素→多 trace）
  → 每格 <TimeCourseCanvas>.setData()
  → CacheDebugOverlay 显示 source(memory/idb/network) + 命中率 + 各层字节/条数
```

**二进制端点**（P1 新增的后端任务，见 §7-G）：在 `GET .../timeseries` 上加 `format=binary`（或 `Accept: application/octet-stream`），复刻 Niantong `EEGBIN01` 思路——`magic + u32 metaLen + JSON meta + float32[times?] + float32[channels, C-order]`，头带 `unit:"µV"`、`sfreq`、`n_channels`、`n_times`、`ch_names`、段信息。**顺带解决单位坑**（后端发 µV、声明 unit）。下采样仍保留（按 `max_points` 适配屏宽）；**全分辨率 / 分块增量去重**留快随（见 §9）。

## 6. 关键决策落地（钉死）

### A. 三因素 facet 布局（本轮核心，参考 LetsWave / Niantong）

- **三因素** = `数据集 dataset / 段 segment（evoked=条件、epochs=试次） / 通道 channel`。
- **指派**：用户把任意两因素指派为网格 **行 / 列**（m×N 子图），第三因素在**每格内叠加**；指派可自由切换（即 Niantong 的「绘图布局：行/列=数据集/事件/通道」分配器、ErpPage 左栏布局按钮已埋此意）。
- **格内呈现**：叠加因素支持 `overlay`（同轴叠色，如多条件对比、蝶形图）与 `spread`（纵向堆叠，如多通道浏览）两种，工具条切换。
- **trace 身份** = `dataset × segment × channel`。取数次数 =（选中数据集数）×（选中段数）；每次请求返该 (dataset,segment) 的全部所选通道。
- **配色语义**：颜色编码「叠加因素」（叠条件→按条件着色、叠通道→按通道着色），用 elys 烙印版 `--c-cat-*`，>8 用 `channelColor(i)` 黄金角兜底。
- **P1 分期**：先做**单数据集**（打开的那个 output）+ {段, 通道} 两因素 facet/叠加；**多数据集对比**（往视图里加别的 output）作快随（需「添加数据集」入口，见 §10）。

### B. 其余

| 决策点 | P1 实现 |
|---|---|
| 配色（①） | **默认 elys 烙印版**（`--c-cat-1..8` = #3F5E8F/#B0544C/#4F8A6B/#B07F33/#5E7BA8/#7B5EA8/#2F8A86/#8A6E5E）+ 黄金角兜底 |
| 段控件（b/d） | epochs：翻页器 + 试次范围；evoked：条件多选（接 facet 段叠加） |
| 单位 | 二进制头声明 unit，后端发 µV；旧 JSON 路径前端 ×1e6 兜 |
| 零线/事件（c） | **本模块不做**（交未来 raw+trigger 模块） |
| 缓存（2.5/e） | 三级瀑布一起上；`CacheDebugOverlay` 由 `import.meta.env.DEV` 或 `?debug=1` 控，发布隐藏 |
| 区间统计（2.6） | 框选 → 右栏均值/峰值/峰值潜伏期（简版逐通道/逐 trace） |
| 传输（f） | **二进制现在就上**（§5 后端 G 任务）；下采样显示保留；分块增量/全分辨率快随 |
| 入口/路由 | 统一 `studyId`+`study_output_id`；三处跳转走后端 `observe_route`；ObserveTabs 透传 query |
