## 0. 一页纸结论（执行摘要）

念析 ELYS 是一个**面向科研级 EEG 团队的"数据治理 + 分析流程 + 多人协作 + 结果可追溯"平台**，技术底座 Python + FastAPI + MNE-Python + Vue。它不和 EEGLAB/MNE 在算法上硬碰，而是在它们之上加**易用性、协作和复现性**这层壳。

**核心判断：**

1. **市场存在但不大**：国内活跃 EEG 分析用户约 **1.5–1.7 万人**，是一个"吃深"而非"跑量"的市场。本土商业化分析软件几乎空白，国产替代窗口期 + 政策红利（2025 七部门 BCI 实施意见）已开。稳定运营后**年收入 200–500 万元是现实目标**，千万级需打开医院 / 机构市场。
2. **产品范围已对齐**：对话设想的模块（预处理 / ERP / 时频 / 溯源 / 脑网络 / 微状态 / 统计 / AI）与 ELYS 路线图 **M4–M12 逐项一致**，且**预处理 + ERP 已跑通**，平台底座（账号 / 数据治理 / BIDS / 工作流 / 追溯 / 双服务器部署）已扎实落地。
3. **唯一战略分歧 = 交付形态**：对话主张 **Electron 本地桌面（数据不出本机）**，ELYS 现状是 **B/S 云端**。但两者**共用同一套后端**，不是二选一 —— ELYS 可以低成本扩展出"服务器版 + 本地版"双形态。
4. **要拍板的关键决策 = wedge（切入楔子）选哪拨人**：你反复强调的痛点（装不了 Python 的学生、忙碌的医生）属于"**个人易用**"persona；ELYS 当前重仓的护城河（协作 / 治理 / 追溯）服务的是"**协作实验室**"persona。两者是不同的人。详见 §11。
5. **执行优势独特**：作为 BCI 领域教授，你有**算法积累 + 数据资源 + 学术背书 + 科研经费养团队**的能力，这是创业公司最难复制的护城河，也意味着**起步阶段近乎零现金成本**。

**本报告推荐路径（待你最终拍板）：** 以 **Electron 本地免费版 + 医生报告端**作为市场验证的"矛头"，快速触达个人易用 persona、规避数据上云顾虑；同时把已建成的 **B/S 协作平台**作为面向实验室 / 机构的"护城河 + 升级位"，分阶段变现。**先访谈 20 个真实用户再定第一个收费模块。**

## 1. 产品定位与边界

### 1.1 一句话定位

> 念析是面向**科研级 EEG 团队**的数据 + 分析 + 协作平台，靠"研究项化数据治理 + 可追溯工作流 + 结构化协作入口"，与单机脚本和公共数据平台**错位竞争**。

- **研究项化数据治理**：把一个课题的数据、协作、权限圈在一个"研究项（Study）"里管。
- **可追溯工作流**：分析流程用"节点图 + 参数版本"记录，半年后回看能精确复现（解决论文复现性痛点）。

### 1.2 目标用户

| 用户 | 场景 | 主要诉求 |
|---|---|---|
| 神经科学研究者 / 研究生 | 实验室日常分析、论文出图 | 易用、降门槛、可复现 |
| 临床电生理医生 | 看报告、临床辅助 | 打开就能看、数据不出院 |
| BCI 开发者 | 算法验证、特征工程 | 开放接口、可扩展 |

### 1.3 产品边界（"必不做"，拒绝越界需求时引用）

不做硬件 / 实时采集；不做 MRI/fMRI（仅溯源时用 MRI 模板）；不做通用统计 / ML 平台（只内置 EEG 常用方法）；不走 NMPA/FDA 临床合规（**定位科研**）；不靠转售公共数据为生；不锁基础功能在付费墙后（**免费版始终可用**）。

## 2. 行业与市场分析

### 2.1 政策与行业背景

- 2024 年中国脑机接口（BCI）市场规模约 **32 亿元**；2025 年工信部等**七部门**联合发布《关于推动脑机接口产业创新发展的实施意见》，国家药监局密集出台行业标准，医保首次为 BCI 服务定价 —— **政策红利正在释放**。
- **脑电分析软件属于产业链中游核心环节**（采集→处理→分析），是 BCI 链条的"中枢"。
- **国产替代空间**：国产高端科研 EEG 设备份额已从五年前不足 15% 升至约 38%，但**分析软件端仍高度依赖国外产品**（EEGLAB 开源、Brain Products、Compumedics Neuroscan 等），本土商业化软件几乎空白 —— **这是最大的结构性机会**。

### 2.2 市场规模（测算假设，需复核）

| 层级 | 国内 | 国际 |
|---|---|---|
| 活跃 EEG 分析用户（≈ TAM） | **1.5–1.7 万人** | **约 6 万人** |
| 增长性 | 受限于有 EEG 设备的实验室总量，**不会快速增长** | 付费意愿更强（外资软件 $500+/年照买） |
| 现实收入目标 | 年 **200–500 万元** | 理论上 5–10 倍用户基数，但需本地化 + 售后投入 |
| 启动建议 | **优先做透国内** | 国内年收入做到 ~100 万级后再启动英文版 |

> 解读：这是一个**"吃深"市场**（争夺同一批人愿不愿付、付多少），不是"跑规模"市场。规模天花板低 → 必须靠**机构 / 医院私有化**和**报告端**开第二、第三条收入线来突破天花板。

### 2.3 竞争格局

| 类别 | 代表 | 强项 | 念析的差异 |
|---|---|---|---|
| 外资商业软件 | Natus、Compumedics Neuroscan、ANT Neuro、BrainVision Analyzer | 临床合规、成熟 | 贵（授权数万至数十万）、本土化差、售后慢 → 念析**本地化 + 易用 + 协作 + 价格** |
| 开源工具 | EEGLAB、FieldTrip、MNE-Python | 算法丰富、免费 | 门槛高（要会编程）、无协作、复现难 → 念析**在其之上加治理 + GUI + 追溯** |
| 国产硬件厂商 | 强脑科技、博睿康、脑陆科技 | 采集硬件强 | **软件端薄弱** → 念析可与之**捆绑销售**（导入其格式，不接管硬件） |
| 公共数据 / 通用工作流 | OpenNeuro、Airflow/Prefect | 数据共享 / 通用调度 | 念析做**私有研究项**、节点为 **EEG/BIDS 量身设计** |

## 3. 用户痛点与价值主张

### 3.1 痛点（两类人，两种痛）

**A. 团队治理痛点（协作实验室 persona）**

| 痛点 | 现状 |
|---|---|
| 工具碎片化 | 数据反复在 EEGLAB / FieldTrip / Analyzer 间导来导去 |
| 复现性差 | GUI 操作难记录、参数靠口头 / 截图传递 |
| 元数据散、追溯成本高 | 半年后回看论文出图，预处理参数对不上 |

**B. 个人易用痛点（个人易用 persona）—— 你反复强调的**

| 痛点 | 现状 |
|---|---|
| 环境配置难 | 用户参加 7 天培训班，回来**连 MATLAB / Python 都装不上** |
| 编程门槛 | 非工程背景研究者用不了脚本工具 |
| 医生没时间 | 医生很忙，根本没空折腾环境，**只想看报告** |
| 数据顾虑 | 自己的数据上传有顾虑；医院数据**不能联网、不能出院** |

### 3.2 价值主张

> **比 EEGLAB 易用、比外资软件便宜且本地化、比脚本可复现、且数据不出本机 / 不出院。**

三个差异化抓手：① GUI 友好 + 一键报告 + 自动去伪迹（替代"研究生手动跑脚本"）；② 对接国产硬件；③ 用 AI 做报告生成 / 异常检测（外资软件更新慢）。

## 4. 产品方案与技术架构

### 4.1 模块范围与当前状态（P0 代码实证）

| 模块 | 能力 | 状态 |
|---|---|---|
| M0 账号权限 | JWT、RBAC、研究项成员权限 | ✅ 已实现 |
| M1 数据管理 | 数据集、研究项、导入、上传版本、FIF | ✅ 已实现 |
| M2 数据质控 | 导入校验已接，信号 QC 待开发 | 🟡 部分接入 |
| M3 工作流 | 节点规格、定义、校验、10 节点执行器 | 🟡 部分接入 |
| M4 预处理 | 滤波 / 重采样 / 重参考 / ICA / Epoch | 🟡 部分接入（**已跑通**） |
| M5 时频 | ERP 已接；PSD / TFR 规划 | 🟡 部分接入 |
| M6 微状态 / M7 脑连接 / M8 溯源 | 高级分析 | ⬜ 规划 |
| M9 观察 / M10 统计 / M11 出图 / M12 ML·AI | 输出与智能 | ⬜ 规划 |

> 现状一句话：**主线"登录 → 研究项 → 导入 → FIF → 工作流 → 执行 → 预处理→ICA→分段→ERP"已跑通**；时频 / 微状态 / 脑连接 / 溯源 / 观察 / 统计 / 出图 / ML 多数仍在规划或静态预览。
>
> ⚠️ 注意：**平台底座（M0/M1/M3）和分析模块的成熟度不对称** —— 治理 / 协作 / 部署投入很重，但能"出科研结果"的分析模块目前只到 ERP。这影响下面的战略排期讨论（§11）。

### 4.2 三种交付形态：一套后端，三种壳

数据隐私 / 医院不出院的矛盾，**有优雅解法**：不是"浏览器连云服务器"，而是按场景切换形态，**后端（FastAPI + MNE + Python）始终是同一套**。

| 形态 | 对象 | 数据在哪 | 实现 | ELYS 现状 |
|---|---|---|---|---|
| **① 本地单机版** | 个人研究者 / 学生 / 忙碌医生 | **只在本机** | Electron / Tauri 把浏览器 + Python 运行时 + MNE 打进 .exe，双击启动连 `localhost` | ❌ 待做（但 FastAPI 已监听 127.0.0.1，距离很近） |
| **② 云协作版** | 多人课题组 | 原始数据留本地，**只同步流程配置（JSON，几 KB）** | B/S，云端只存 Pipeline / 模板 / License | ✅ 已建（B/S 双服务器） |
| **③ 私有化部署** | 医院 / 大型机构 | **完全在院内内网** | Docker 镜像，院内 `docker run`，离线 License | 🟡 架构支持（计算服可迁内网），未打包 Docker |

**关键洞察 —— 双形态不冲突，反而是优势：**

- ELYS 的 FastAPI **本来就监听 `127.0.0.1:8000`**，与"本地版连 localhost"是同一底层形态。从现架构到"出本地单机版"只差两步：(a) 本地版把 PostgreSQL 换成 SQLite 级轻量库；(b) 用 PyInstaller / Tauri 打包 MNE + Python 运行时。**Vue vs React 无关**（Electron 壳包任意 web 前端）。
- 服务器成本几乎为零：云端只存几十 KB/用户的 Pipeline JSON + License，一台小云服务器月成本几百元；**EEG 计算用用户自己的 CPU**。
- **"数据永不离开您的电脑"可直接作为官网卖点**，对临床研究者是比竞品更强的信任背书。
- 医院版与科研版**同一套代码**，只换部署方式；私有化卖 License 无算力成本，**¥5 万/年近乎纯利润**。

### 4.3 分析端 vs 报告端：拆成两个产品

> 医生不做分析，他们**看报告**。这是两个需求，应是两个产品、两个合同、两条收入线。

- **分析端**（Electron 桌面）：给技术员 / 研究生 / 研究者，导出**结构化报告**（PDF / 加密报告，几百 KB），不导出原始数据。
- **报告端**（纯 web，可部署院内网）：给医生，浏览器登录看波形 / 结果 / 诊断建议，**服务器上只有报告摘要，无原始 EEG**。开发成本低。

> ⚠️ ELYS 现状缺口：[wiki 1-20] 用户角色里**没有"报告查看者"角色，也没有报告端产品** —— 这是本报告建议新增的产品线。

### 4.4 远程支持能力（本地版需补，服务器版已天然具备）

- 服务器版：代码跑在你控制的服务器上，**天然有全量日志和可观测性**，支持比 Electron 更直接。
- 本地版需内置：崩溃自动上报（Sentry）、一键发送日志、使用行为分析（Mixpanel，需授权）、**静默自动更新**。

### 4.5 技术栈

`Vue 3` `TypeScript` `Pinia` `Vite` `LiteGraph.js`（可视化工作流）｜ `FastAPI` `Pydantic 2` `SQLAlchemy 2` `MNE-Python` `NumPy/SciPy` ｜ `PostgreSQL` `Redis`（Celery 异步）`Nginx`。本地版增 `PyInstaller / Tauri / Electron`。

## 5. 商业模式与定价

### 5.1 模式：Overleaf 式 freemium（免费引流 + 订阅变现）

Overleaf 成功的本质不是"免费给 LaTeX"，而是**消除安装门槛 + 一键协作 + 模板降低学习曲线** —— 这三件在 EEG 领域都有真实需求。**关键调整**：Overleaf 处理 KB 级文本，EEG 是 100MB–10GB/被试的文件，照搬"全云端"会被存储 / 算力成本压垮，且有隐私顾虑 → 采用 **"本地计算 + 云端协作"** 变体（见 §4.2）。

### 5.2 定价档位（测算假设）

| 档位 | 对象 | 形态 | 价格 | 包含 |
|---|---|---|---|---|
| **免费版** | 个人 / 学生 | 本地单机 | **¥0** | 全功能本地运行、数据不出本机、无被试数限制 —— **对抗 EEGLAB 的核心武器** |
| **个人 Pro** | 重度个人用户 | 本地 + 云协作 | **¥199/月** 或 **¥1,288/年** | 流程模板共享、参数云同步、一键报告、AI 辅助 |
| **实验室版** | 5–10 人课题组 | 云协作 / 私有 | **¥3,000–6,000/年** | 多人协作审查、权限管理、共享 Pipeline |
| **机构私有化** | 医院 / 大机构 | Docker 内网 | **¥5 万/年起**（另议） | 离线 License、数据不出院、近乎纯利润 |
| **报告端** | 医院 IT / 临床科室 | 内网 web | 按院授权（另议） | 医生看报告，与分析端**分开签约** |

> 定价对标的不是 EEGLAB（开源免费），而是**"节省研究生 2 个月学习时间"的价值**。

### 5.3 收入结构

三条腿：**个人 / 实验室订阅**（基本盘，受 1.5 万天花板约束）＋ **机构 / 医院私有化 License**（突破天花板、高毛利）＋ **报告端按院授权**（新增线）。科研阶段走"订阅 + 高校集采"，医疗阶段走"SaaS + 私有化部署"双轨。

## 6. 市场规模与财务测算

> ⚠️ 以下全部为**情景假设**，用于规模感与融资节奏规划，非承诺。混合 ARPU（每用户年均收入）假设 ¥1,300–1,800。

### 6.1 收入情景

| 情景 | 时点 | 可触达基数 | 付费转化率 | 付费用户 | 混合 ARPU | 订阅收入 | +私有化 | **合计/年** |

| **早期** | ~18 个月 | 5,000 | 4% | 200 | ¥1,300 | ¥26 万 | — | **~¥26 万** |

> 与 §2.2 的"年收入 200–500 万现实、千万需医院 / 机构"一致：**订阅基本盘吃透天花板约 200 万，私有化 + 报告端再叠 100–300 万**。

### 6.2 团队成本与盈亏平衡

| 阶段 | 团队 | 年人力成本 | 自给所需付费用户（@¥1,300） | 资金来源 |
|---|---|---|---|---|
| **起步** 0–12 月 | 你 + 1–2 名博士生 | **≈ 0** | — | 科研经费 / 横向课题 |
| **验证后** 12–24 月 | + 1–2 名工程合伙人 | ¥60–100 万 | ~500–800 | 经费 + 早期订阅 |
| **规模化** 24 月+ | 6 人专职 | **¥240–300 万** | **~2,000** | 订阅 + 私有化 +（融资） |

> **最重要的一个数字**：养 6 人专职团队 → 需约 **2,000 付费用户**才能自给，按当前转化预期需 **2–3 年**积累。**在此之前用科研经费 / 横向课题养团队，是你作为教授的独特优势 —— 起步现金压力近乎为零。**

## 9. 关键决策与下一步行动

### 9.1 待你拍板的决策

1. **【最关键】wedge persona 选哪边？**
   - **A. 个人易用** → 优先做 Electron 本地免费版 + 报告端，直击你反复提的痛点，零服务器负担，最快验证付费意愿。
   - **B. 协作实验室** → 继续打磨现 B/S 平台，吃 RBAC / 协作 / 追溯的高护城河，但跑道更长、且痛点人群不同。
   - **C. 双形态分阶段**（本报告推荐）→ A 做矛头验证市场，B 作为护城河 + 升级位，共用一套后端。
2. **双形态排期**：本地版与现平台谁先？建议本地版 MVP 与 Phase 2 分析引擎并行。
3. **报告端是否立项**：要不要把"报告查看者"角色 + 报告端产品正式排进路线图。

### 9.2 立即可做（不依赖上面拍板）

1. **2 周内访谈 20 个真实用户**：5 在读研究生 + 5 青年教师/博后 + 5 临床医生 + 5 BCI 工程背景，每人 30 分钟，问"上周分析数据时最卡在哪一步"。**这比任何市场报告都准**，直接决定第一个收费模块。
2. **盘点你手里的资产**：已有算法积累、数据资源、横向课题 —— 决定哪个模块能最快做出差异化。
3. **复核本报告的市场 / 财务数字**：用一手调研 + 行业报告替换附录 A 的二手来源，再对外使用。

### 9.3 本报告的推荐路径（一句话）

> **用 Electron 本地免费版 + 医生报告端做市场矛头（验证个人易用 persona、规避上云顾虑），把已建成的 B/S 协作平台作为面向实验室 / 机构的护城河与升级位，分阶段变现；动手扩模块前先访谈 20 人。**
