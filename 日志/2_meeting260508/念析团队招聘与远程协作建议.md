# 念析团队招聘与远程协作建议

> 整理日期: 2026-05-14  
> 适用阶段: 念析 EEG 分析平台从 Demo / v1 走向可维护产品阶段  
> 核心判断: 项目不是普通 CRUD 系统, 而是科研软件平台 + EEG 数据工程 + 科学计算 + 可视化 + 统计分析的组合。

## 1. 项目对人的要求

从现有 wiki 看, 念析的核心需求包括:

- 文件管理与 BIDS 存储: 项目、被试、会话、Run、原始格式到 FIF、元数据管理。
- EEG 预处理: 滤波、重采样、重参考、坏道、坏段、ICA、Epoch、Baseline。
- 数据分析: ERP、PSD、TFR、微状态、脑网络、溯源。
- 观察与可视化: 多通道波形、时频图、地形图、连接图、3D 脑模型。
- 统计与论文结果: t 检验、ANOVA、混合效应模型、多重比较、cluster permutation。
- 机器学习: 特征提取、分类/回归、AutoML、XAI。
- 工程平台: Vue 3、TypeScript、FastAPI、MNE-Python、Celery、Redis、PostgreSQL、NAS、Nginx。

因此不能只按「前端 + 后端」普通互联网团队来招, 需要至少覆盖三类能力:

1. 工程化能力: Web、后端、数据存储、部署、权限、安全、可维护性。
2. EEG / 科学计算能力: MNE、NumPy、SciPy、ICA、ERP、PSD、TFR、数据格式。
3. 心理/认知科研能力: 实验设计、统计、论文表达、图表、结果解释。

## 2. 程序员招聘建议

### 2.1 推荐团队结构

早期不建议一次招太多人。更稳的组合是:

| 角色 | 地点建议 | 职责 | 优先级 |
|---|---|---|---|
| 技术负责人 / 架构负责人 | 深圳或广州 | 架构、代码评审、需求拆分、部署、质量把关、与创始团队线下沟通 | P0 |
| EEG 科学计算后端 | 武汉 / 西安 / 成都 | MNE、BIDS、预处理、ICA、ERP/PSD/TFR、异步任务、缓存 | P0 |
| 前端可视化工程师 | 成都 / 武汉 / 西安 / 广州 | Vue/TS、LiteGraph、ECharts/Plotly/uPlot、多通道波形和大数组可视化 | P1 |
| DevOps / 部署安全 | 兼职或外包 | Nginx、HTTPS、服务器、备份、日志、监控、等保准备 | P1 |
| 脑电算法顾问 | 高校/医院/实验室兼职 | 审核预处理口径、统计口径、科研可信度 | P0 兼职 |

### 2.2 城市性价比

| 城市 | 推荐岗位 | 判断 |
|---|---|---|
| 武汉 | EEG 后端、科学计算、数据分析、维护 | 科教资源强, 性价比高, 适合远程核心开发 |
| 西安 | 信号处理、算法后端、科学计算 | 电子信息与信号处理人才多, 成本低于深圳 |
| 成都 | 后端、前端、工程化、远程团队 | 软件人才供给成熟, 远程协作稳定性较好 |
| 广州 | 混合办公前端/后端、脑电顾问 | 离深圳近, 可定期线下, 成本略低于深圳 |
| 长沙/合肥 | 测试、维护、普通后端 | 成本低, 但高级 EEG 算法人才相对少 |
| 深圳 | 技术负责人、产品沟通、关键架构 | 适合放核心负责人, 不适合把所有岗位都放深圳 |

参考 2025 软件行业人月费率口径, 深圳明显高于武汉、长沙、西安、成都。实际招聘时不要机械按人月费率定薪, 但可以判断相对成本: 武汉/西安/成都通常可比深圳节省 20%-30% 以上, 维护岗位差距更明显。

### 2.3 是否推荐远程协作

推荐, 但不推荐松散外包。建议采用:

> 深圳核心负责人 + 异地远程工程师 + 强代码评审 + 明确测试数据和验收标准

远程协作规则:

- 每个任务拆到 3-7 天内可验收。
- 每个 PR 必须有测试、截图、计算结果或示例数据输出。
- EEG 算法模块必须有 sample data 和 golden result。
- 每周 2 次同步会: 一次需求/进度, 一次技术/质量。
- 每月或每 6 周做一次集中评审。
- 敏感 EEG 数据不要随意发到个人电脑, 用脱敏样例、VPN/NAS 或私有服务器。
- 所有核心流程写成可复现脚本, 不接受「只在我电脑上跑通」。

### 2.4 程序员面试重点

后端 / EEG 科学计算:

- 是否用过 MNE、NumPy、SciPy、h5py、pandas。
- 是否理解 Raw、Epochs、Evoked、Spectrum、TFR、ICA。
- 是否知道 EEG 数据为什么要 BIDS / FIF / HDF5。
- 能否解释滤波、重采样、重参考、坏道、ICA、epoch、baseline。
- 是否有大文件处理和异步任务经验。
- 是否能写可测试的纯函数, 而不是把算法全部塞进路由。

前端可视化:

- 是否做过大数组可视化、Web Worker、二进制传输、虚拟滚动。
- 是否熟悉 ECharts、Plotly、D3、uPlot 或类似高性能图表库。
- 是否能理解多通道 EEG 波形、时间光标、地形图联动。
- 是否能做工程化 TypeScript / Vue 组件, 而不是一次性 Demo。

技术负责人:

- 是否能拆解科研软件需求。
- 是否能约束代码结构、测试策略和部署策略。
- 是否能协调算法、前端、产品和数据分析人员。
- 是否能识别「看起来能跑, 但科研上不可信」的问题。

## 3. EEG 数据分析师招聘建议

这个岗位不应按商业数据分析师来招, 而应招:

> 心理学 / 认知神经科学 / 神经工程背景的数据分析师

核心能力:

- 懂 EEG 数据分析流程: 滤波、坏道、ICA、epoch、baseline、reject。
- 懂 ERP、PSD、TFR、时窗、频段、通道选择。
- 懂统计: t 检验、重复测量 ANOVA、线性混合模型、非参数检验、多重比较。
- 懂论文写作: Methods、Results、图注、统计报告、supplement 参数表。
- 能使用 R / Python / MATLAB 中至少一种做可复现分析。

### 3.1 数据分析师城市建议

| 优先级 | 城市/区域 | 原因 |
---|---|---|
| 1 | 武汉 | 华中师范、武汉大学等心理/认知方向人才多, 成本低于深圳 |
| 2 | 重庆/成都 | 西南大学心理学强, 成都科研和医疗数据环境成熟 |
| 3 | 西安 | 陕西师范、电子信息和信号处理人才基础好 |
| 4 | 广州/佛山 | 华南师范、中山大学资源近深圳, 适合混合办公/顾问 |
| 5 | 长沙/南京/天津 | 可招硕士研究助理型人才, 适合维护分析和文献整理 |
| 不优先 | 北京/上海 | 人才强但成本高, 更适合找兼职专家, 不适合作性价比全职 |

### 3.2 数据分析师薪酬区间

粗略建议:

- 远程硕士级 EEG 数据分析师: 10k-18k/月。
- 能独立做统计、写结果、懂论文逻辑: 15k-25k/月。
- 博士/高校背景专家顾问: 兼职 5k-15k/月, 或按项目计费。
- 深圳本地同水平人才: 通常上浮 20%-40%。

### 3.3 面试作业建议

给候选人一个小 EEG 数据集或公开数据集, 要求交付:

1. 可复现脚本或 notebook。
2. 预处理流程说明。
3. ERP/PSD/TFR 至少一种分析结果。
4. 统计方法选择理由。
5. 一张论文风格图。
6. Methods + Results 短文。

重点看候选人是否能解释:

- 为什么用这个滤波范围。
- 为什么选这个时窗/频段/通道。
- 为什么用这个统计模型。
- 如何处理多重比较。
- 结果是否过度解释。

| 角色 | 数量 | 触发条件 |
|---|---:|---|
| 前端可视化工程师 | 1 | 预处理/观察/作图进入真实用户测试 |

## 5. 结论

早期不要把预算压在「深圳本地全职大团队」上。更好的方式是:

> 深圳保留技术和产品核心, 武汉/西安/成都招远程科学计算与数据分析, 高校/医院专家做兼职审查。

这样能在成本、脑电专业性和长期维护之间取得更好的平衡。
