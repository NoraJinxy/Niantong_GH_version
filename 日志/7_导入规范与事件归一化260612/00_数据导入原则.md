## 0. 一句话目标

导入后的数据,**必须能"按 condition 切分 + 时频分析"**,而不是停在 econ 那种「876 个唯一事件、Epoch 节点选不出类」的死局。

## 1. 根因(一句话)

econ 把 trial 序号烧进了事件标识符(`trial/cue_sent/index/7/clench_fist`)→ 876 条全唯一;Epoch 节点按 `event_id` 逐字符串精确匹配、UI 又有 64 条上限 → **选不出"类"**。详见 memory `econ_bdf_import`。

## 2. 地基:两层事件模型

**标准化发生在"你的门口"(ingest),不在"别人的文件"。** 文件格式(EDF+/BDF+ 的注释)是自由文本,管不了内容——所以在导入边界立规矩:

- **原始照收**:设备写的注释一字不改地留(事实源,可回溯/可重映射)。
- **派生 condition**:另产出一份"有界、语义化"的分析用标签。
- 对齐 BIDS:`events.tsv` 存原始 onset/duration + 一列 `trial_type`(= 干净 condition)。

## 3. 导入七原则

### 事件层(踩坑的地方)
1. **原始照收,另立 condition。** 不丢原始;另派生干净 condition 给分析用。
2. **condition 有界、语义化、不带实例数据。** 取值数应 ≈ 实验因素水平数(2–8),不是 trial 数;名字是「握拳/放松」,不是 `trial/idx/7/clench_fist`。
3. **实例数据(trial 序号/run/参数)进独立列,绝不拼进标签。** 这一条根除 876。
4. **锚点与类别都要可得;拿不到就 join。** 每段 epoch 要能定"何时起"+"属哪类";若两者分散在不同事件,导入时按 trial 序号拼成一行。
5. **映射每研究定义一次,复用全部 recording。** 一研究 = 一范式 + 一设备 = 一套触发,配一次即可。

### 信号层(时频分析的地基)
6. **采样率/单位/通道名:确定且标准化。** `sfreq` 正确(onset 秒→样点不偏)、单位明确(µV/V)、通道用标准 10-10 名。
7. **留足窗 + 基线,别切坏边界。** epoch + 时频要有刺激前基线和足够窗长;别把首尾 trial 截得没了基线。

## 4. 那把尺子(litmus)+ 导入 QC 五项

**尺子:数事件"不同取值"的个数。若 ≈ trial 数,或"抹掉数字后的模板数 ≪ 唯一数",就说明标识符里烧了序号 → 未归一化 → 下游一定切不动。**
(已实现:`engine/analysis/event_conditions.summarize_event_vocabulary` → 对 econ 返回 `verdict=instance_laden, n_unique=876, n_templates=15`。)

导入 QC 五项:
- [ ] 事件非空,且所有 onset 落在记录时长内
- [ ] **condition 取值数有界**(报警:超过阈值 或 ≈ trial 数 → 判"未归一化")
- [ ] 每个 condition 的 trial 数够用(≥ 阈值,够平均/统计)
- [ ] `sfreq` / 单位 / 通道名 齐全且标准
- [ ] 原始注释已留存(可回溯、可重映射)

## 5. condition 的定义,与 HED/BIDS 衔接(可选第二步)

- condition = **有界语义标签**;UI 只让用户在 condition 名里选,匹配规则(含/正则)藏进配置层。
- 进阶:把每个 condition 挂上 **BIDS `trial_type` 语义 + 可选 HED 标签**(受控词表,可校验、跨研究可比)。
- 公开数据:把"HED 合法"做成 **QC badge**(三态 passed/failed/none、钉 schema 版本、绑数据版本),**先亮灯不硬拦**,需要时再 warn→block。详见上一轮 HED/QC 讨论。

## 6. 明确不做(YAGNI)

- **不在导入期写死分组**:分组是分析期决策(同数据可按 cue / mode / 预测对错切),提前烧死就失灵活。
- **不一上来强制 HED**:先 badge,warn→block 爬坡,且要先有"预设自动吐合法 HED"的工具,否则把人挡在门外。
- **不为单一设备写特判**:econ = 标准 BDF+,导入侧已全支持(见 `econ_bdf_import`);要解的是通用的"事件归一化",不是 iRecorder 特判。
