## 元素全景速览

两大业务域 + 横切机制:

- **数据资产域**(跨研究项复用):数据集 → 数据集版本 → 采集记录 → 上传版本,配套文件索引 `dataset_files`、引用追踪、撤回申请。
- **研究域**(协作与权限边界):研究项 →(挂载数据集,锁定版本)→ 工作流 → 执行项 → 输出。
- **横切**:权限三环、审计、并发锁(编辑锁 + 单活跃运行锁)、异步任务。
- **可追溯性骨干**:执行创建时冻结输入快照(`pipeline_execution_inputs`)与定义快照;输出带完整来源链(execution/job/node/params + 上游 id);删除前查下游依赖(被引用则 409 拦截)。

## 生命周期一览(状态枚举以 schema CHECK 为准)

| 对象 | 状态轴 | 枚举值 |
|---|---|---|
| 数据集(资产) | status | `working / archived† / deleted / quarantined` |
| 数据集(资产) | visibility | `private → shared → public`(只升不降) |
| 数据集版本 | state | `unpublished → published → withdraw_requested → withdrawn`(终态) |
| 采集记录 | qa_status | `pending` 起,转换后更新(指示用,不作硬门槛) |
| 上传版本 | status | `current / replaced / rejected / failed` |
| 研究项 | status | `active / archived† / trashed`(+ deleted_at,回收站可恢复,purge 硬删仅 admin) |
| 工作流 | status | `draft / active / archived† / deleted`(+ version 乐观锁) |
| 执行项 | status | `queued / running / waiting_user_input / completed / failed / canceled` |
| 输出 | 三层正交 | `keep`(布尔)+ `cache_eligible`(布尔)+ `deleted_at`(回收站)+ `purged_at`(GC 已清盘标记,P5 已落地待云端验证) |
| 异步任务 | status | `queued / running / succeeded / failed / canceled / retrying` |

† 标记 = "死态":CHECK 约束里有这个值、读路径会过滤它,但全后端没有任何端点能把对象写成这个状态(2026-06-10 grep 验证)。

## 权限三环

1. **平台 RBAC**:角色 `admin` / `pi`(seed 仅此两个) + 权限码(`data:read`、`data:write`、`study:write` 等)。admin 独占:研究项硬删(purge)、撤回审核、紧急下架。
2. **研究项成员**(`study_members`):角色 `owner / editor / viewer` + 五个细粒度布尔(`can_read / can_write / can_delete / can_export / can_run`),统一走 `require_study_read/write/run()`。
3. **数据集授权**(`dataset_members`):邀请制,仅 visibility=shared 档生效;private 走主研究项成员;public 对任意注册用户。
