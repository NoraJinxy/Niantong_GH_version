## 六、风险与注意点

- **`can_read` 加 `db` 参数**：调用点多（详情/列表/文件读取/关联），改动面广；判「主研究项成员 / dataset_members 授权」要用 **join 批量**，避免 N+1。
- **关联网关传 actor**：`_ensure_version_mountable` 签名变了，要把 `current_user` 从路由一路传到 service，沿途签名都改。
- **仅暴露已发布版本（R7）**：文件列举、BIDS 树、下载三条读链都要堵，别漏其一造成草稿外泄。
- **删除端点前置严判**：整体删仅限「无任何已发布/已撤回版本」的纯未发布资产；已发布历史一律不可删，防误删。
- **可见范围无降级**：前端不给降级入口、后端不给降级端点，两头都要堵；「取消共享」的诉求引导到「私有 + 团队成员」。
- **调试期 DROP 重建**：确保 `elys_debug.cmd` 能从零把新 schema + `superadmin` 角色 + `dataset_members` + 测试数据一并建起。
- **行号复核**：本清单行号基于 2026-06-09 master，动手前先 grep 复核。
